# Segurança

Use as referências de segurança deste repositório para aprendizado e prevenção. Não execute testes contra sistemas de terceiros sem autorização explícita.

Para reportar uma vulnerabilidade neste repositório, use o recurso **Report a vulnerability** do GitHub quando disponível. Não publique detalhes exploráveis em uma issue pública.

Este projeto é um catálogo editorial; não garante que links ou orientações substituam análise profissional, requisitos legais ou documentação vigente dos fabricantes.
