# Skill: Qualidade de software

Garantir e medir a qualidade do software.

## Quando usar

Definir critérios de qualidade, revisões de código, métricas e gates de CI.

## Conceitos principais

- Modelo de qualidade do produto (ISO/IEC 25010)
- Revisão de código
- Análise estática e linters
- Dívida técnica
- Métricas (defeitos, complexidade, tempo de entrega)

## Boas práticas

- Automatize lint, formatação e testes no CI
- Faça code review em toda mudança
- Defina uma Definição de Pronto com critérios de qualidade
- Registre e priorize dívida técnica
- Meça tendências, não números absolutos

## Armadilhas comuns

- Métricas usadas como meta (lei de Goodhart)
- Revisões apenas de estilo
- Ignorar avisos de ferramentas
