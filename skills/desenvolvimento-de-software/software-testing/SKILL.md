# Skill: Testes de software

Planejar e escrever testes automatizados.

## Quando usar

Garantir comportamento correto, prevenir regressões e apoiar refatoração.

## Conceitos principais

- Níveis: unidade, integração, sistema, aceitação
- Pirâmide de testes
- Test doubles (mocks, stubs, fakes)
- Cobertura e testes de mutação
- Testes de regressão e determinismo

## Boas práticas

- Testes rápidos, isolados e determinísticos
- Um comportamento por teste, com nome descritivo
- Rode toda a suíte no CI a cada mudança
- Teste casos de borda e de erro
- Corrija ou remova testes instáveis (flaky)

## Armadilhas comuns

- Testes acoplados à implementação
- Cobertura alta com asserções fracas
- Testes dependentes de ordem ou de rede externa

## Checklist

- [ ] Testes rápidos, isolados e determinísticos
- [ ] Um comportamento por teste, com nome descritivo
- [ ] Rode toda a suíte no CI a cada mudança
- [ ] Teste casos de borda e de erro
- [ ] Corrija ou remova testes instáveis (flaky)
