# Skills para agentes

> As skills são material editorial do Tech-Repo, derivado das fontes registradas em cada `fontes.yml`. Em caso de divergência, a documentação oficial prevalece.

## Como usar

1. Leia o `SKILL.md` da tecnologia antes de executar a tarefa.
2. Siga o checklist e confirme detalhes na documentação oficial vinculada.
3. Ao alterar uma skill, mantenha links apenas para fontes já registradas em `fontes.yml` (veja `AGENTS.md`).
