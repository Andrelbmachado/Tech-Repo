# Tech-Repo

Biblioteca bilíngue de referências técnicas para pessoas e sistemas de IA. Cada tecnologia tem uma pasta própria com resumos originais, metadados estruturados e referências oficiais. Quando a licença autoriza redistribuição, também mantemos cópias locais dos documentos oficiais, identificadas e versionadas.

**Navegação rápida:** [Mapa](MAPA.md) · [Tecnologias](MAPA-TECNOLOGIAS.md) · [Índice para IA](INDICE-IA.yaml) · [Catálogo](CATALOG.yml) · [Manutenção](MAINTENANCE.md) · [Contribuir](CONTRIBUTING.md) · [Segurança](SECURITY.md)

## Como consultar

1. Use o [mapa](MAPA.md) para escolher uma área.
2. Leia o `README.md` da tecnologia para a visão resumida em português e inglês.
3. Consulte `tech.yml` e `fontes.yml` para identidade, versão, autoridade, licença e referências.
4. Confirme informações sensíveis a versão na documentação original, indicada em `fontes.yml`.
5. Para cópias offline autorizadas, procure a pasta `documentacao-oficial/` dentro da tecnologia e leia o `README.md` dela antes de usar os arquivos.

## Política editorial

- Prioridade: mantenedores e organismos normativos; em seguida documentação oficial de fornecedores, projetos open source e fontes comunitárias identificadas.
- Cada tecnologia busca cinco referências oficiais relevantes. Se não houver cinco fontes adequadas, registre `partial` e justifique; durante a pesquisa, use `pending`.
- O repositório publica resumos próprios e links. Só inclui arquivos oficiais de terceiros quando a licença ou autorização permite; cada cópia deve preservar os avisos e registrar origem, edição, data, licença e checksum.
- Um link em `fontes.yml` não significa que o documento foi baixado. A presença de uma cópia offline deve ser declarada no `README.md` da tecnologia e acompanhada de manifesto local.
- Padrões pagos ou restritos são identificados e referenciados sem cópia integral.
- Resumos são bilíngues. Títulos originais e termos técnicos permanecem como publicados.

## Estado inicial

O catálogo lista tecnologias em diferentes etapas. `curated` identifica conteúdo revisado; `in-progress` indica material inicial em elaboração; `planned` reserva a entrada para uma onda futura. A quota de cinco fontes é registrada separadamente e não é declarada completa enquanto não verificada.
